# AUTOMATED-MANUFACTURING-DEFECT-DETECTION-SYSTEM-
AI-based manufacturing defect detection system that uses computer vision and image processing to identify product defects such as cracks, scratches, deformation, and missing components.
# Manufacturing Product Defect Detection

## 1. Introduction

This project focuses on detecting manufacturing product defects using Artificial Intelligence and Computer Vision. The system analyzes product images and identifies whether the product is normal or contains defects.

## 2. Problem Statement

Manual inspection of manufactured products can be time-consuming and may result in human errors. This project aims to automate the defect detection process using an AI-based image analysis system.

## 3. Objectives

* Detect defects automatically from product images.
* Identify different types of manufacturing defects.
* Reduce manual inspection effort.
* Improve the accuracy and efficiency of quality inspection.

## 4. Defects Detected

* Cracks
* Scratches
* Deformation
* Missing Components
* Normal / No Defect

## 5. Technologies Used

* Python
* OpenCV
* Machine Learning / Deep Learning
* NumPy
* Pandas
* Matplotlib

## 6. Dataset

The dataset contains images of normal and defective manufacturing products. The images are categorized according to the type of defect.

## 7. Methodology

1. Collect product images.
2. Preprocess the images.
3. Prepare and organize the dataset.
4. Train the AI model.
5. Test the model using new images.
6. Detect and classify product defects.
7. Evaluate model performance.

## 8. Model Performance

The model is evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score

## 9. Results

The trained model can identify defective and non-defective products from input images.

## 10. Future Enhancements

* Add more product types and defect categories.
* Increase the size of the dataset.
* Improve model accuracy.
* Implement real-time defect detection.
* Develop a web or mobile application for defect inspection.

## 11. Conclusion

This project demonstrates how Artificial Intelligence and Computer Vision can be used to automate manufacturing quality inspection and detect product defects efficiently.
